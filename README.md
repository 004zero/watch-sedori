# 腕時計せどりナビ（watch-sedori）

「電池交換すれば動く」ジャンク腕時計の見極めと、ヤフオク／メルカリ／Yahoo!フリマ／ラクマ／セカスト・ハードオフ／eBay／買取店の
仕入れ元 × 販売先ルートで差額が取れる組み合わせを判定する静的ツール（`index.html` + `data.js` の2ファイル）。

## 起動
- `起動.bat` をダブルクリック（http://localhost:3340）
- または `index.html` を直接ブラウザで開いても動きます

## タブ
1. **モデル相場・ルート** … 176モデルのジャンク相場／メルカリ／ヤフオク／セカスト／eBay の目安帯、最良ルートと差額利益、ジャンク期待利益
2. **ジャンク判定** … 出品文を貼ると「電池交換で復活する確率」「修理コスト」「販売先別手取り」「期待利益」「仕入上限」
3. **ルート計算** … 仕入値と想定売値から販売先ごとの手取り・利益・仕入上限。モデル別の仕入れ元×販売先マップ
4. **実データ取り込み** … ブックマークレットで各サイトの実測相場を取り込み、モデルに保存（localStorage）
5. **仕入れ候補** … 判定した案件の管理・ステータス・CSV出力
6. **設定** … 手数料・送料・為替・修理コスト・目標利益
7. **ガイド** … ムーブ別の狙い目、電池型番表、裏蓋と工具、ルート別の特徴、真贋・古物商・出品テンプレ

## 計算の考え方
- 手取り = 売値 × (1 − 手数料%) − 送料 − 梱包。eBay は関税・返品引当%も控除
- 差額利益 = 最も手取りが大きい販売先 − 最も安い仕入れ元の中央値（送料込）
- ジャンク期待利益 = 復活確率 × (手取り − 仕入 − 安い処置) + 失敗確率 × max(本格修理して売る, ジャンクのまま再販)
- 仕入上限 = 期待利益が目標利益（max(最低利益額, 手取り×目標利益率)）になる仕入価格
- 復活確率 = ムーブメントの基礎点（クォーツ70・デジタル65・ソーラー50・キネティック35・機械式15・スマートウォッチ20）± 出品文のキーワード
