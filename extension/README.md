# 腕時計せどりナビ Chrome拡張

ヤフオク・メルカリ・Yahoo!フリマのページ上で、腕時計の「電池交換で直る見込み」「相場」「買い／見送り」を1クリックで判定します。
Webツール（https://004zero.github.io/watch-sedori/）と同じ相場DB・判定ロジックを使います。

## インストール（開発者モード）
1. このリポジトリを ZIP でダウンロードして展開（https://github.com/004zero/watch-sedori/archive/refs/heads/main.zip）
2. Chrome で `chrome://extensions` を開く
3. 右上「デベロッパー モード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」→ 展開した中の **`extension` フォルダ** を選ぶ
5. ツールバーのパズルアイコンから「腕時計せどりナビ 拡張」をピン留め

## 使い方
- **商品ページ**（ヤフオク／メルカリ／Yahoo!フリマ）：右下の「⌚ 判定」を押す
  - 型番からモデルを自動推定 → 裏タブでヤフオク落札・メルカリ売切・Yahoo!フリマ売切の相場を取得（10〜20秒、24時間キャッシュ）
  - 「買い／値下げ待ち／見送り」「復活確率」「買っていい上限」「売る先と手取り」「期待利益」を表示
  - モデルが違うときはパネルのプルダウンで選び直す
  - 「🤖 AIで写真と説明を判定」：Claude が写真と説明文から液晶劣化・液漏れ・偽物リスク・状態を読み、復活確率と売値を補正（要APIキー）
  - 「候補に保存」→ 拡張アイコンのポップアップで一覧・CSV出力
- **検索結果ページ**：右下の「⌚ 一覧を判定」を押すと、各商品に判定バッジ（買い／見送り・上限・期待利益）が付きます（モデル最大10種・商品60件まで）

## 設定（拡張アイコン →「設定」）
- Claude APIキー（AI判定に必要。キーはブラウザ内にのみ保存され api.anthropic.com 以外には送られません）
- モデル：Claude Opus 5.5（標準）／Sonnet 5.5／Haiku 5.5
- 手数料・送料・目標利益・修理コスト（Webツールと同じ項目）

## 注意
- 相場取得は「自分が検索結果ページを開いて見る」のと同じ操作を裏タブで行います。短時間に大量に実行しないでください（サイトの利用規約と負荷への配慮）。
- サイトのHTML構造が変わると取得件数が0になることがあります。その場合は `background.js` の scrape 関数のセレクタを直してください。
- `data.js` と `core.js` はWebツール本体（1つ上のフォルダ）のコピーです。更新は `node sync-ext.js` で反映します。

## ファイル
- `manifest.json` … 権限・対象ページ
- `content.js` … ページ上のボタン・パネル・一覧バッジ（判定計算）
- `background.js` … 相場取得（裏タブ）・Claude API・保存
- `core.js` / `data.js` … 判定ルール・モデルDB（Webツールと共通）
- `options.*` … 設定画面、`popup.*` … 候補一覧
